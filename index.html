    How it works

    The same three steps, whatever the pile.

    1. Bring a pile

    An array, a CSV, a folder of photos, or a URL on your own server that returns JSON.

    2. Decide fast

    One card at a time, with the whole message or picture on it. Undo any press. Close early and it asks to save what you decided.

    3. Save once

    Your code gets the answers: move the files, call your API, post to a webhook, or download the list. Failures are named, and can be tried again.

    Put it in your app

    Plain JavaScript, MIT licensed. Works in any page, framework or back end.

    <link rel="stylesheet" href="pile-sprint.css">
<script src="core.js"></script>
<script src="pile-sprint.js"></script>
<script>
  PileSprint.open({
    title: "Leads to qualify",
    items: leads.map(l => ({ id: l.id, title: l.name, subtitle: l.company, body: l.note })),
    kinds: { default: { keep: "Call them", drop: "Not a fit" } },
    save: {
      keep: lead => fetch(`/api/leads/${lead.id}/call`, { method: "POST" }).then(r => r.ok),
      drop: lead => fetch(`/api/leads/${lead.id}/archive`, { method: "POST" }).then(r => r.ok)
    }
  }).then(result => console.log(result.saved, result.failed));
</script>
